# SA-TV Android source starter

Branded app label: SA-TV

Master playlist bundled at `app/src/main/assets/master.m3u` from the user's uploaded `bengali_merged.m3u`.

Remote master playlist URL:
`https://raw.githubusercontent.com/sovandey/bengal-iptv-data/main/bengali_merged.m3u`

This package is a rebranded starter source, not a finished app or APK. The playlist is bundled as a source asset, but the current starter UI does not yet parse/display it in the channel list. Not Working reporting, playback-confirmed URL replacement, secure admin publishing, and Android TV home-screen channels are not complete. No Firebase or paid backend is configured.

Build requires AndroidIDE or Android Studio with compatible Android SDK/Gradle/JDK. A successful build and device test have not been performed here.
